# RedScribe V3 Release Guide

Release: `3.0.0`

RedScribe V3 release 3.0.0 is additive: V2 routes and behaviour remain intact. Every branch registers routes, entity kinds, migrations, and tokens as data through the B00 contracts. The app remains offline-only, with no runtime dependencies, no network calls, and no code-execution path.

## Onboarding and first run

- **Welcome to RedScribe** (required) — A local-first notebook for captures, findings, evidence, and reports. `data-step=welcome`
- **Record your first capture** (required) — Create a note to anchor the engagement timeline. `data-step=first-capture`
- **Confirm local storage** (required) — Your vault is stored on disk and never sent to a remote service. `data-step=confirm-local`
- **Review the design system** (required) — See panels, metrics, kind colors, density, and motion tokens. `data-step=review-basics`
- **Start your engagement** (optional) — Add a target and move your first note into a finding. `data-step=start-engagement`
