# Keyboard shortcuts

## Global

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | New note using the last template |
| `Ctrl+Shift+N` | New folder |
| `Ctrl+P` | Quick switch (fuzzy note search) |
| `Ctrl+Shift+F` | Full-text search |
| `Ctrl+Shift+S` | Snippet library |
| `Ctrl+Shift+D` | Dashboard |
| `Ctrl+Shift+P` | Pin or unpin the current note |
| `Ctrl+E` | Cycle Write / Split / Preview |
| `Ctrl+S` | Save the current note |
| `Ctrl+,` | Settings |
| `Ctrl+F` | Find in the current note |
| `Ctrl+H` | Find and replace |
| `F2` | Edit note properties |
| `Delete` | Move the selected tree item to trash (tree focus) |
| `F1` | Keyboard shortcuts dialog |

## Tree

| Shortcut | Action |
| --- | --- |
| `Ctrl+Up` / `Ctrl+Down` | Move the selected note or folder among its siblings |
| `F2` | Rename the selected note or folder |
| `Delete` | Move the selected note or folder to trash |
| Drag and drop | Drop on a folder to move inside it, or between rows to reorder |

Drag a row to the empty area below the tree to move it back to the vault root.

## Editor

| Shortcut | Action |
| --- | --- |
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+K` | Inline code |
| `Ctrl+Shift+X` | Strikethrough |
| `Ctrl+A` | Select all |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Tab` / `Shift+Tab` | Indent / outdent the selection |
| `Enter` | Continue lists, tasks, and block quotes |
| `Ctrl+F` / `Ctrl+H` | Find / replace within the note |

## Find bar

| Shortcut | Action |
| --- | --- |
| `Enter` | Next match |
| `Shift+Enter` | Previous match |
| `Escape` | Close the find bar |

The find bar is local to the current note. Use `Ctrl+Shift+F` to search the
whole vault and `Ctrl+P` to jump by title, tag, or target.
